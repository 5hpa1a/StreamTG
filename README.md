# 📡 StreamTG — Telegram-бот оповещений о стримах (Twitch, Kick, YouTube)

Асинхронный Telegram-бот на базе `aiogram 3.x` и `SQLite`, который автоматически отслеживает начало и завершение прямых трансляций на платформах **Twitch**, **Kick** и **YouTube**, публикует и динамически редактирует анонсы в Telegram-канале, а также ведёт ежемесячную статистику эфирного времени с выгрузкой в CSV/Excel.

---

## ✨ Основные возможности

* **Единый профиль игрока (мультистриминг):** к одному никнейму можно привязать сразу 3 платформы (Twitch, Kick, YouTube) с единым баннером и текстом оповещения.
* **Динамическое редактирование постов:**
  * При старте стрима бот публикует пост с изображением, текстом и ссылкой на активную платформу.
  * Если параллельно запускается стрим на второй платформе — бот автоматически редактирует существующий пост и добавляет ссылку на второй стрим.
  * Если одна из платформ завершает эфир, а другая продолжает — ссылка на отключившуюся платформу убирается из поста.
* **Защита от реконнектов (Grace Period — 5 минут):** когда все трансляции игрока переходят в офлайн, бот ждёт 5 минут перед удалением поста из канала на случай кратковременного обрыва связи или перезапуска потока.
* **3 режима оформления ссылок в постах (переключаются в боте на лету):**
  1. **Гиперссылки:** `TWITCH | KICK | YOUTUBE` (или просто `TWITCH`, если активна одна платформа) в конце текста поста.
  2. **Прямые URL-ссылки:** открытые ссылки в конце текста поста.
  3. **Инлайн-кнопки:** кнопки-ссылки под постом.
* **Учёт статистики и выгрузка в Excel/CSV:**
  * Автоматический подсчёт суммарного времени стримов по каждому игроку и платформе за месяц.
  * Автоматическая публикация сводного отчёта в канал 1-го числа каждого месяца в формате `Никнейм-Платформа-Суммарное время`.
  * Мгновенная выгрузка таблицы `.csv` (в кодировке `UTF-8-SIG` для прямого открытия в Microsoft Excel) через админ-панель.
* **100% кнопочное управление:** добавление игроков, привязка/отвязка платформ, смена фото и текста, предпросмотр поста и просмотр статистики выполняются через интерактивные меню без ввода текстовых команд.
* **Минимум API-ключей:**
  * **Twitch** — официальный Helix API (бесплатные `Client ID` и `Client Secret`).
  * **Kick** — прямое обращение к API канала через `curl_cffi` с эмуляцией TLS-отпечатка браузера Chrome (в обход Cloudflare, без ключей).
  * **YouTube** — парсинг статуса `ytInitialPlayerResponse` со страницы `/live` без расхода жестких квот YouTube Data API v3.

## ⚙️ Предварительная подготовка

### 1. Создание Telegram-бота и подготовка канала
1. Перейдите в [@BotFather](https://t.me/BotFather), создайте нового бота командой `/newbot` и скопируйте `BOT_TOKEN`.
2. Добавьте созданного бота в ваш Telegram-канал в качестве **Администратора** и выдайте ему права:
   * *Публикация сообщений (Post messages)*
   * *Изменение чужих сообщений (Edit messages of others)*
   * *Удаление чужих сообщений (Delete messages of others)*
3. Узнайте ID вашего канала (он начинается с `-100...`) и ваш личный Telegram ID (например, переслав сообщение из канала в [@userinfobot](https://t.me/userinfobot) или [@getmyid_bot](https://t.me/getmyid_bot)).

### 2. Получение ключей Twitch (бесплатно, занимает 2 минуты)
1. Перейдите в [Консоль разработчика Twitch](https://dev.twitch.tv/console) и авторизуйтесь.
2. Нажмите **Register Your Application**.
3. Заполните поля:
   * **Name:** любое уникальное название (например, `MyStreamNotifierApp`).
   * **OAuth Redirect URLs:** `http://localhost`
   * **Category:** `Chat Bot`
   * **Client Type:** `Confidential`
4. Нажмите **Create**, затем откройте созданное приложение кнопкой **Manage**.
5. Скопируйте **Client ID** и нажмите **New Secret**, чтобы получить **Client Secret**.

## 🚀 Установка и запуск

### На Windows (PowerShell)

1. Клонируйте репозиторий и перейдите в папку проекта:
   ```powershell
   git clone [https://github.com/5hpa1a/StreamTG.git](https://github.com/5hpa1a/StreamTG.git)
   cd StreamTG
   ```
2. Создайте и активируйте виртуальное окружение:
   ```powershell
   python -m venv venv
   Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
   .\venv\Scripts\Activate.ps1
   ```
3. Установите зависимости:
   ```powershell
   pip install -r requirements.txt
   ```
4. Создайте рабочий файл конфигурации из шаблона:
   ```powershell
   copy config.example.py config.py
   ```
5. Откройте `config.py` в любом редакторе и укажите ваши `BOT_TOKEN`, `CHANNEL_ID`, `ADMIN_IDS`, `TWITCH_CLIENT_ID` и `TWITCH_CLIENT_SECRET`.
6. Запустите бота:
   ```powershell
   python main.py
   ```

---

### На Linux-сервере (Ubuntu / Debian)

1. Клонируйте репозиторий и перейдите в каталог:
   ```bash
   git clone [https://github.com/5hpa1a/StreamTG.git](https://github.com/5hpa1a/StreamTG.git)
   cd StreamTG
   ```
2. Создайте виртуальное окружение и установите зависимости:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```
3. Создайте и заполните `config.py`:
   ```bash
   cp config.example.py config.py
   nano config.py
   ```
4. Запустите бота:
   ```bash
   python main.py
   ```

#### Автозапуск в фоне на Linux через `systemd`
Создайте файл `/etc/systemd/system/streamtg.service`:
```ini
[Unit]
Description=StreamTG Telegram Notifier Bot
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/StreamTG
ExecStart=/opt/StreamTG/venv/bin/python /opt/StreamTG/main.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```
Активируйте и запустите службу:
```bash
sudo systemctl daemon-reload
sudo systemctl enable --now streamtg
sudo journalctl -u streamtg -f
```

## 🎛 Использование админ-панели

1. Откройте диалог с ботом в Telegram с аккаунта, чей ID указан в `ADMIN_IDS`, и нажмите `/start` (или кнопку **«🎛 Панель управления»**).
2. **➕ Добавить игрока / канал:**
   * Введите никнейм игрока (если игрок уже существует в базе, бот автоматически предложит привязать к его профилю дополнительную платформу).
   * Выберите платформу (`TWITCH`, `KICK`, `YOUTUBE`).
   * Отправьте ссылку на канал (например, `https://www.twitch.tv/s1mple` или просто `s1mple`).
   * Отправьте картинку для поста (как фото).
   * Отправьте текст оповещения (поддерживаются стандартные эмодзи и любое форматирование Telegram: жирный, курсив, цитаты, скрытые ссылки).
3. **📋 Список игроков:**
   * Позволяет просматривать текущий статус стримов каждого игрока (`🟢 LIVE` / `⚫️ Офлайн`).
   * Привязывать дополнительные платформы или удалять ненужные.
   * Менять изображение или текст оповещения.
   * Вызывать **«👁 Предпросмотр поста»** для проверки внешнего вида карточки в личных сообщениях.
4. **🔗 Ссылки:** переключает глобальный стиль отображения ссылок на стримы (`Гиперссылки TWITCH | KICK`, `Прямые ссылки` или `Инлайн-кнопки`). Все активные посты в канале обновляются автоматически.
5. **📊 Статистика за месяц:** отображает суммарное время стримов за текущий месяц, позволяет выгрузить таблицу `.csv` для Excel или опубликовать сводку в канал.
